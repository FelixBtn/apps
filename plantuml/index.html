PlantUML Studio

PlantUML diagrams for Confluence Cloud, with an AI assistant, clean exports and a converter for diagrams pasted from ChatGPT or Claude. It shares its editor with Mermaid Studio.

Get started

  1. A Confluence administrator installs the app from the Atlassian Marketplace.
  2. Edit a page, type /plantuml and choose PlantUML diagram.
  3. The editor opens with a starter diagram. Change the code, or describe what you need to the AI assistant, then click Save and publish the page.

Code without a @startuml line is accepted: the app adds @startuml and @enduml for you.

Editor and AI assistant AI

The editor works like the one in Mermaid Studio: code with a live preview, syntax errors highlighted on their line, templates and themes. See the editor and AI assistant documentation.

  • Templates: sequence, use case, class, activity, component, state, entity relationship, C4 container, mind map and Gantt.
  • Themes: Auto follows Confluence's light or dark mode; you can also pick Default or Dark. Exports always use the light theme.
  • AI: describe a system or a process in any language, for example "booking app: website, API, database, external payment service", and the AI writes the PlantUML. It can also apply a change, fix a syntax error or explain the diagram. Each site has a monthly number of AI requests, shown next to the AI bar: 20 on the free tier, 50 during a trial, 200 with a paid subscription.

C4 architecture diagrams

The C4-PlantUML library is included. Start your diagram with !include <C4/C4_Context>, <C4/C4_Container> or <C4/C4_Component>, or insert the C4 container template. Other !include <…> libraries (for example AWS or Kubernetes icons) and includes from URLs are not available, because the app does not connect to anything outside Atlassian.

Convert pasted code blocks

  1. Open the page (not in edit mode) and click ••• in the top right.
  2. Choose Render PlantUML code blocks.
  3. The app lists code blocks marked plantuml or puml, and, if you keep the option on, code blocks without a language that start with @startuml or another @start line. Each block is checked; blocks with errors are not selected.
  4. Click Convert, then Reload page. A new page version is created, so you can restore the previous one from the page history.

PDF and Word export

When you save a diagram, the app stores an image of it (plantuml-diagram-….png) as a page attachment. Confluence uses it in PDF and Word exports, so exports show the diagram, not its code. Please keep these attachments. If a diagram was changed outside the editor, open it in the editor and save it again.

What is supported

The app uses the official PlantUML engine (version 1.2026.8), compiled to JavaScript, so diagrams are drawn in your browser. Supported: sequence, use case, class, object, activity, component, deployment, state, timing, entity relationship, C4, mind map, WBS, Gantt, JSON and YAML diagrams, and more. Graph layouts use PlantUML's built-in layout engine instead of Graphviz, so complex layouts can differ slightly from PlantUML's website. Links in diagrams are not clickable.

Where your data goes

  • The app runs on Atlassian's infrastructure and has no connection to any other server. Diagrams are drawn in your browser.
  • Diagram code is stored in your Confluence page; export images are page attachments.
  • AI requests go to Atlassian-hosted models and are not stored by the app.
  • Details: privacy policy and security.

Troubleshooting

"Diagram error on line N" / "Syntax Error?"

PlantUML could not read that line. Open the editor: the line is highlighted and Fix with AI can repair it. PlantUML guesses the diagram type from the first lines, so a typo there can make it read the whole diagram as the wrong type.

"Cannot include" or an include error

Only the C4 library is available. Remove other !include lines, or copy the definitions you need into the diagram.

Something else

Contact us through the help center; include your site address and, if possible, the diagram code and a screenshot.
