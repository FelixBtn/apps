Security

Last updated: 29 October 2026

Architecture

  • Runs on Atlassian. Mermaid Studio is an Atlassian Forge app. Its code runs on Atlassian's infrastructure and it does not connect to any server outside Atlassian. It has no egress permissions, which Atlassian verifies for the "Runs on Atlassian" programme.
  • Rendering in the browser. Diagrams are drawn in the reader's browser inside Atlassian's sandboxed app frame, with Mermaid's strict security level, which removes scripts, click handlers and HTML from diagram labels.
  • Least privilege. The app only asks for the permissions it uses: reading and updating pages (to convert code blocks when a user asks), reading and writing attachments (to store export images), and app storage (to count AI requests). Calls to Confluence are made as the current user, so the app can never see or change content the user cannot.
  • AI through Atlassian. AI features use Forge LLMs: models hosted by Atlassian, subject to Atlassian's content moderation. Prompts are not sent to any third party by us and are not stored by the app.
  • No secrets or credentials are stored by the app.
  • Dependencies are pinned, checked with npm audit before each release, and updated when advisories are published.

Reporting a vulnerability

Please report suspected vulnerabilities privately through our help center: https://felixb-support.atlassian.net/servicedesk/customer/portal/3. Choose Report a bug and start the summary with [Security], or email help@felixb-support.atlassian.net with [Security] in the subject. Do not include exploit details in public places. We acknowledge security reports within 24 hours.

The app also takes part in Atlassian's Marketplace security programme; reports made through Atlassian reach us as well.

Fix timeframes

We follow the Atlassian Marketplace security bug fix policy for cloud apps, counted from when a vulnerability is reported or triaged:

Severity (CVSS)Fixed within
Critical (9.0 and above)10 days
High (7.0 to 8.9)4 weeks
Medium (4.0 to 6.9)12 weeks
Low (below 4.0)25 weeks

Incidents

If a security incident affects customer data, we inform affected customers and Atlassian without undue delay, and in any case within 72 hours of becoming aware of it, with what happened, what data is concerned and what we are doing about it.
