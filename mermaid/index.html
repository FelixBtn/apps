Get started

  1. A Confluence administrator installs the app from the Atlassian Marketplace.
  2. Edit a page, type /mermaid and choose Mermaid diagram.
  3. The editor opens with a starter diagram. Change the code, or describe what you need to the AI assistant, then click Save and publish the page.

To change a diagram later, edit the page, select the diagram and click the edit (pencil) button.

The diagram editor

  • Code on the left, live preview on the right. The preview updates as you type.
  • Syntax errors appear under the code with the line number, and the line is highlighted.
  • Insert template offers starters: flowchart, sequence, class, state, entity relationship, Gantt, mind map, timeline, pie chart and git graph. Undo brings back your previous code.
  • Theme: see themes.
  • Keyboard: Tab indents, Esc then Tab leaves the code area, Ctrl/⌘ + S saves.
  • Syntax help opens the Mermaid syntax reference.

AI assistant AI

The purple AI bar at the top of the editor works in any language.

  • Generate: describe a diagram, for example "expense approval: the employee submits, the manager approves amounts over €500, finance pays", and the AI writes the Mermaid code. Labels follow the language you write in.
  • Apply: when the editor already contains your own diagram, describe a change, for example "add a QA step before Deploy", and the AI updates the code.
  • Fix with AI appears on syntax errors and repairs the code with the smallest possible change.
  • Explain describes the diagram in plain language, in your Confluence language.

Always check what the AI produces before saving. Undo restores your previous code.

Each Confluence site has a monthly number of AI requests, shown next to the AI bar. The counter resets on the 1st of each month (UTC).

Convert pasted code blocks

When you paste an answer from ChatGPT, Claude or another assistant, Confluence keeps Mermaid diagrams as code blocks. To turn them into diagrams:

  1. Open the page (not in edit mode) and click ••• in the top right.
  2. Choose Render Mermaid code blocks.
  3. The app lists the Mermaid code blocks on the page and checks that each one is valid. Blocks with errors are not selected. With Also detect Mermaid in code blocks without a language, code blocks without a language that start like a diagram are included too.
  4. Click Convert, then Reload page.

The conversion saves a new version of the page, so you can restore the previous version from the page history.

Zoom, pan and full screen

  • Hover a diagram to show its toolbar: zoom out, zoom level (click to fit), zoom in, full screen.
  • Ctrl/⌘ + mouse wheel zooms; when zoomed, drag to move around; double-click to reset.
  • With the diagram focused, +, − and 0 zoom in, zoom out and reset.
  • Full screen opens the diagram as large as your screen allows; there, the mouse wheel zooms directly.

PDF and Word export

When you save a diagram, the app also stores an image of it (PNG) as an attachment of the page, named mermaid-diagram-….png. Confluence uses this image when the page is exported to PDF or Word, so exports show the diagram, not its code. Please keep these attachments.

If a diagram was changed without the editor (for example through the API), open it in the editor and save it again to refresh its image. Until then, PDF exports draw the live diagram and Word exports show its code.

Themes and dark mode

With the Auto theme (the default), diagrams follow Confluence's light or dark mode. You can also pick a fixed Mermaid theme: Default, Neutral, Forest, Dark or Base. Exports always use a light theme so diagrams print well.

Supported diagrams

The app uses Mermaid 12 and supports all its diagram types, including flowchart, sequence, class, state, entity relationship, user journey, Gantt, pie, quadrant, requirement, git graph, C4, mind map, timeline, Sankey, XY chart, block, packet, kanban, architecture, radar, treemap and Venn diagrams. See the Mermaid documentation for the syntax.

Limits

  • Diagrams up to 200,000 characters and 2,000 edges.
  • AI: descriptions up to 2,000 characters and diagrams up to 20,000 characters, within the monthly requests of your site.
  • Links, click handlers and HTML inside diagram labels are disabled for security.

Where your data goes

  • The app runs on Atlassian's infrastructure and has no connection to any other server.
  • Diagram code is stored in your Confluence page; export images are page attachments.
  • AI requests go to Atlassian-hosted models and are not stored by the app.
  • Details: privacy policy and security.

Troubleshooting

"Diagram error on line N"

The Mermaid code has a syntax error on that line. Open the editor: the line is highlighted and Fix with AI can repair it. Common causes: a label with parentheses or quotes that needs double quotes, such as A["Review (legal)"], or a node called end.

The export shows code instead of the diagram

Open the diagram in the editor and click Save to store a fresh image, then publish the page and export again.

"This site has used its AI requests for this month"

The monthly AI limit of your site is reached. It resets on the 1st. The editor and all other features keep working.

Something else

Contact us through the help center; include your site address and, if possible, the diagram code and a screenshot.
