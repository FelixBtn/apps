Mermaid Studio for Jira

Mermaid diagrams on Jira work items, with the same editor and AI assistant as Mermaid Studio for Confluence. Mermaid code pasted into a description is drawn automatically.

Get started

  1. A Jira administrator installs the app from the Atlassian Marketplace.
  2. Open a work item and click the Mermaid diagrams button under the summary (with the other app buttons).
  3. The panel appears above the activity, and the editor opens. Write Mermaid code or describe the diagram to the AI assistant, then click Save.

Jira administrators can show the panel on every work item: in the panel's ••• menu, choose Show for all work items.

The Mermaid diagrams panel

  • Each diagram has Edit and Delete buttons. Delete asks for confirmation.
  • Add diagram adds another diagram to the work item.
  • Hover a diagram for zoom and full screen; Ctrl/⌘ + mouse wheel zooms.
  • Refresh reloads the diagrams and the description. Changes made by other people appear on their own; your own edits to the description need a refresh.
  • With the Auto theme, diagrams follow Jira's light or dark mode.

Diagrams from the description

Answers from ChatGPT, Claude and other assistants often contain Mermaid code blocks. Paste them into the work item description: the panel draws every code block marked mermaid, and code blocks without a language that start like a Mermaid diagram, under From the description. Your description is not changed.

Edit a copy opens one of these diagrams in the editor and saves it as a panel diagram you can change.

Editor and AI assistant AI

The editor is the same as in Confluence: code with a live preview, errors highlighted on their line, templates and themes. The AI bar can generate a diagram from a description, apply a change, fix a syntax error or explain the diagram, in any language. See the editor and AI assistant documentation.

Each Jira site has its own monthly number of AI requests, shown next to the AI bar: 20 on the free tier, 50 during a trial, 200 with a paid subscription. The counter resets on the 1st of each month (UTC).

Who can do what

  • Anyone who can see the work item can see its diagrams.
  • Adding, changing and deleting diagrams needs the Edit work items permission. The app acts as the signed-in user, so Jira checks this itself.
  • If the subscription is not active, diagrams stay visible but cannot be changed.

Limits

  • Up to 20 diagrams per work item, and 32 KB of diagram code per work item in total (a Jira limit; a typical diagram is well under 1 KB).
  • The same Mermaid and AI limits as in Confluence: see limits.

Where your data goes

  • The app runs on Atlassian's infrastructure and has no connection to any other server.
  • Diagrams are stored on the work item itself, in a work item property named mermaid-studio. They are deleted with the work item.
  • The description is read in your browser to find Mermaid code; it is not stored.
  • AI requests go to Atlassian-hosted models and are not stored by the app.
  • Details: privacy policy and security.

Troubleshooting

"You need permission to edit this work item"

Your Jira role does not allow editing this work item. Ask a project administrator for the Edit work items permission.

A code block in the description is not drawn

Mark the code block's language as mermaid, then click Refresh. Code blocks without a language are only drawn when they start with a diagram type, such as flowchart or sequenceDiagram, and have no errors.

"Diagram error on line N"

Open the diagram in the editor: the line is highlighted and Fix with AI can repair it.

Something else

Contact us through the help center; include your site address, the work item key and, if possible, the diagram code and a screenshot.
